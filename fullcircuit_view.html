Full circuits — reading structure instead of norms

Every panel is computed from weights alone, no forward pass. The difference from the composition-score view is that nothing is collapsed to a scalar: these are the actual contracted circuit matrices, so you can see what the interaction is rather than only how big it is. LayerNorm gain folded, embeddings mean-centred.

2 · Induction full circuit  Ê WQKdst WOVsrc Êᵀ

Rows = destination (the head doing the reading), deepest layer at the top. Columns = source (the head doing the writing), deepest layer at the left. Every later head reads the whole residual stream, so every source-below-destination cell exists; the hatched block is same-layer and structurally impossible. An induction circuit is a tile with a bright main diagonal — "attend where the previous token equals the current token". Click to select.
